# Checklist de liberação do piloto gratuito

- [ ] Repositório GitHub é PRIVATE.
- [ ] Render > New > Web Service, não Blueprint.
- [ ] Instance Type = FREE. Sem disco, sem outro banco pago.
- [ ] Senha e contato cadastrados em Environment no Render, não no GitHub.
- [ ] Health check informa `pilot_only=true`.
- [ ] Acesso administrativo por HTTPS no celular.
- [ ] Vaga fictícia cadastrada e perguntas específicas por categorias.
- [ ] Resposta por texto com colagem convencional bloqueada.
- [ ] Áudio fictício enviado e retomável durante a mesma sessão.
- [ ] Whisper Tiny: transcrição de teste concluída; revisar palavra por palavra.
- [ ] Transcrição não inventada se áudio incompreensível.
- [ ] Nota técnica avaliada pelo recrutador enquanto não houver motor contextual.
- [ ] Parecer exportado sem método de cálculo ou referência à IA.
- [ ] Confirmada fragilidade: após hibernação dados desaparecem. **Não iniciar entrevistas reais.**
